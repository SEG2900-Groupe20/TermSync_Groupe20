--------------------------------------------------
1. RÈGLES GÉNÉRALES
--------------------------------------------------
- Un fichier CSS par page (css/pages/), plus css/components.css (navbar et
  footer) chargé sur toutes les pages. Mêmes couleurs, mêmes composants partout.
- Toujours commencer le CSS d'une page par la réinitialisation :

    * { box-sizing: border-box; }

- Garder le CSS simple : pas de bibliothèque ni de framework. Seule ressource
  externe autorisée : la police Plus Jakarta Sans (Google Fonts).
- Pas de dégradé : couleurs unies uniquement (le rouge du bandeau est uni).
- Langue du site : français. Les rôles de l'équipe gardent "Software Engineer".
- Une page = son fichier CSS, et son fichier JS seulement si elle en a besoin
  (js/pages/). Ne pas créer de fichier vide.

4. FORMES ET ESPACEMENTS
--------------------------------------------------
Arrondis (border-radius) :
- Boutons de la navbar, pastilles : 999px (forme "pilule")
- Boutons principaux et secondaires : 12px
- Cartes : 20px à 24px  (grands blocs : 28px à 32px)
- Photos de l'équipe, pastilles d'icônes, cercles : 50%
- Appareils (mockups) : ordinateur 18px, téléphone 26px, tablette 20px

Ombres (box-shadow) :
- Carte normale   : 0 12px 30px -18px rgba(17, 16, 25, 0.25)
- Carte au survol : 0 24px 40px -20px rgba(164, 28, 28, 0.4)
- Bouton rouge    : 0 10px 24px -10px rgba(164, 28, 28, 0.7)
- Menu            : fine bordure basse #e5e5e5

Largeurs : contenu max 1240px avec 24px de marge de chaque côté (classe
.conteneur ou max-width équivalent). Le contenu des pages et celui de la
navbar et du footer sont alignés.

Espacements courants : 8, 12, 16, 24, 32, 48, 56, 72, 96px
(rester sur ces valeurs pour garder un rythme visuel cohérent)

5. COMPOSANTS RÉUTILISABLES
--------------------------------------------------

5.1 NAVBAR  (js/utils/navbar.js + css/components.css)  - sur TOUTES les pages
- Insérée dans <div id="navbar"></div> ; script dans le <head> avec defer.
- Position fixe en haut, fond blanc semi-transparent, bordure basse, z-index 1000.
- Logo (Official_logo.png) à gauche, liens à droite, bouton "Commencer" en rouge
  plein (pilule).
- Lien de la page actuelle : bordure rouge, texte rouge, gras (aria-current).
- Burger sur petit écran (max-width 768px).
- Ne jamais recréer de menu dans le CSS d'une page ; ne pas styler .top-menu
  ni .menu-item ailleurs que dans components.css.

5.2 FOOTER  (js/utils/footer.js + css/components.css)  - sur TOUTES les pages
- Inséré dans <div id="footer"></div> en bas du <body> ; script avec defer.
- Pleine largeur (#footer : width 100%), même quand le body est en flex centré.
- Logo + slogan "Votre trimestre, synchronisé.", puis 3 colonnes : Produit,
  Entreprise, Légal, puis ligne de copyright.
- Contenu aligné sur 1192px (1240 - 2 x 24).
- Pour modifier un lien : changer la liste en haut de footer.js.

5.3 BOUTONS
- Principal (.btn-primary) : fond #a41c1c, texte blanc, 12px, hauteur 52px,
  gras, ombre rouge. Survol : léger soulèvement (translateY(-2px)).
- Secondaire (.btn-secondary) : fond blanc, bordure 1.5px #e9bcbc, texte noir,
  12px, hauteur 48px. Survol : bordure et texte rouges.
- Sur fond sombre : .btn-light (blanc, texte rouge) et .btn-contour (bordure
  blanche).
- Bouton "Télécharger" (accueil) : fixe en bas à gauche, rouge plein.

5.4 CARTES
- Fond blanc, bordure 1px #e7e5f0, arrondi 20px, ombre légère.
- Survol : translateY(-6px), bordure #e9bcbc, ombre rouge douce.
- Apparition au défilement : classe .reveal puis .visible (JS, IntersectionObserver).
- Pastille de problème (Solutions) : fond #f8e3e3, texte #a41c1c, pilule.
- Icône de carte : carré arrondi blanc, bordure #e9bcbc, icône rouge (traits
  de 2px, style Feather).

5.5 LISTE À ICÔNES (accueil)
- Une icône ronde blanche à bordure rose par ligne, une icône DIFFÉRENTE et
  adaptée à chaque phrase (robot, appareil photo, cloche, courbe).
- Le mot clé de chaque ligne est en gras et en noir.

5.6 PAGE TARIFS  (carrousel de plans)
- 4 plans nommés par une note : C (0 $), B+ (3,99 $), A+ (6,99 $), A* (12,99 $).
- .card : 320px de large, arrondi 24px, texte aligné à gauche, avantages sur UNE
  ligne (30 caractères environ) ; sur mobile le retour à la ligne est permis.
- .card.center (plan actif) : rouge, opacity 1, scale(1.08), grosse ombre.
- .card.side (autres plans) : NOIR (#111019), opacity 0.5, scale(0.85),

- .indicators / .dot : 20px x 6px, #e9bcbc ; .dot.active : #a41c1c, 32px.
- .controls / .nav-btn : cercle de 48px, bordure 2px #a41c1c, fond blanc.
- Le plan du milieu (A+) est actif au départ ; le JS lit le nombre de cartes.

5.7 PAGE ÉQUIPE
- Une carte par personne (.member-card), la photo ronde (160px) alterne de côté,

- Trois lignes par personne :

--------------------------------------------------
7. RESPONSIVE
--------------------------------------------------
Breakpoint principal : @media (max-width: 768px)
Breakpoints secondaires : 1000px (grilles à 2 colonnes), 900px (pages légales),
820px (accueil), 640px (Équipe), 720px (footer).

Sur mobile :
- Les grilles passent en une colonne, les boutons restent faciles à toucher.
- Tarifs : les cartes passent en colonne (90%), plus de zoom ni de transparence.
- Accueil : la section Termsync s'empile, sans courbes.
- Solutions : la scène fichiers - TermSync - calendrier passe en colonne.

=> Toute nouvelle page doit rester lisible sous 768px.
=> Respecter prefers-reduced-motion : couper les animations et transitions.

--------------------------------------------------
8. CONVENTIONS DE CODE
--------------------------------------------------
- Fichiers en minuscules, sans espace ni accent : liste-cours.html
- Classes CSS en minuscules, mots séparés par un tiret :
  .menu-item, .page-title, .card-content, .member-card
- États avec une classe supplémentaire : .active, .center, .side, .visible,
  .is-visible
- Ordre dans un fichier CSS :
    1) variables et reset  2) body  3) titres  4) composants
    5) états (hover, actif)  6) responsive (@media) à la fin
- Indentation : 2 espaces. Commentaires courts, en français.
- Transitions douces : 0.25s pour les survols.
- Variables JS en camelCase ; fonctions courtes, JavaScript natif.
- Supprimer le code et les fichiers inutilisés (CSS orphelin, JS vide).
- Chaque page : <title> "Nom de la page | TermSync", lang="fr", favicon.

--------------------------------------------------
8. CODING CONVENTIONS
--------------------------------------------------
- Lowercase file names, no spaces or accents: liste-cours.html
- Class names in lowercase, words separated by a hyphen:
  .menu-item, .page-title, .card-content, .member-card
- States use an extra class: .active, .center, .side, .visible, .is-visible
- Order within a CSS file:
    1) variables and reset  2) body  3) titles  4) components
    5) states (hover, active)  6) responsive (@media) at the end
- Indentation: 2 spaces. Short comments, in French.
- Smooth transitions: 0.25s for hover effects.
- JS variables in camelCase; short functions, plain JavaScript.
- Delete unused code and files (orphan CSS, empty JS).
- Every page: <title> "Page name | TermSync", lang="fr", favicon.
